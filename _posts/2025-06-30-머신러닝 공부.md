### 1. 머신러닝이란 무엇인가?

- **머신러닝**: 컴퓨터가 규칙을 명시적으로 코딩하지 않고, 데이터(경험)를 바탕으로 스스로 패턴을 학습하는 기술
- 학습이란 프로그램이 경험을 통해 작업 성능을 향상시키는 과정  
  - 예: 스팸 이메일 분류

---

### 2. 머신러닝이 가능해진 배경

- 사용 가능한 데이터가 폭발적으로 증가
- 컴퓨터 성능의 발전
- 머신러닝 기술은 오래전부터 존재했으나, 2010년 이후 데이터와 컴퓨팅 자원의 성숙으로 실제 활용 가능해짐

---

### 3. 인공지능? 빅데이터? 머신러닝?

- **인공지능(AI)**: 컴퓨터 프로그램이 인간처럼 생각하거나 행동하게 하는 학문
- **머신러닝(ML)**: AI를 달성하기 위한 하나의 방법
- **딥러닝(Deep Learning)**: 머신러닝 기법 중 하나로, 여러 층(layer)을 깊게 쌓아 복잡한 패턴을 학습
- **빅데이터**: 방대한 데이터를 저장·처리·분석하는 분야

---

### 4. 딥러닝의 지도학습과 비지도학습

- **지도 학습 (Supervised Learning)**  
  - ‘정답’을 알고 있고, 그 정답을 맞추는 것이 학습의 목적  
  - 학습 데이터에 반드시 정답(Label)을 알려줘야 함  
  - 직관적이며, 실제로 많이 사용됨

| 분류(Classification) | 회귀(Regression) |
| --- | --- |
| 두 가지 이상의 범주로 데이터를 구분 | 연속적인 값 예측 |
| 예: 스팸 메일 분류 | 예: 아파트 가격 예측 |

- **비지도 학습 (Unsupervised Learning)**  
  - 정답이 주어지지 않은 상태에서 데이터를 스스로 비슷한 그룹으로 나누거나 패턴을 찾음

---

### 5. k-NN 알고리즘

- 가장 가까운 이웃 데이터 k개를 찾아, 이웃들의 결과를 기반으로 예측
- k-NN은 머신러닝 알고리즘 중 하나
- 데이터(경험)가 많을수록 성능이 향상됨 → 머신러닝의 특징
- 예: 타이타닉 탑승자 데이터를 이용해 생존 여부 예측 (지도학습 중 분류 문제)

---

### 6. 머신러닝의 수학

- 머신러닝은 **컴퓨터 과학 + 수학**으로 이루어짐
- 올바른 알고리즘 선택과 코드 최적화를 위해 최소한의 수학 지식 필요
- 머신러닝 수학의 주요 분야
  - **선형대수학**: 행렬을 활용해 대량 데이터를 효율적으로 다룸
  - **미적분학**: 모델의 최적화 과정에 사용
  - **통계학**: 데이터의 전반적 경향을 파악하고 예측
  - **확률론**: 결과의 가능성을 계산하고 판단

---

> **한 줄 요약**  
> 머신러닝은 방대한 데이터를 바탕으로 컴퓨터가 스스로 학습해 성능을 높이는 기술로, 오늘날 AI와 빅데이터 시대를 이끄는 핵심 기술이다.
